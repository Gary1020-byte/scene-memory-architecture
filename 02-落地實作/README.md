# 02 · 落地實作

> 從「看懂」到「蓋起來」，再到「回來改」。
> 這裡是**規格**、**校驗**、**維護**三件事。

| 篇 | 一句話 | 給誰 |
|---|---|---|
| [一-目錄與檔案規格](一-目錄與檔案規格.md) | 目錄結構、檔案格式、命名約定——**可照抄的規格** | 要蓋的人 |
| [二-交接與校驗](二-交接與校驗.md) | 五項機械不變量、換會話協議、反例驗收表 | 要維護的人 |

## 一句話

> **規格是給人抄的，校驗是給機器守的，維護手冊是給未來的你看的。**

```
                                                        ▲
                                     四-已知裂縫與待修 ───┘
                                      （這就是「要改了」的理由來源）
```
