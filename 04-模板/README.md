# 04 · 模板

> 可直接拷貝的純殼。**拷完必須按你自己的內容改**——
> 這些是「形狀」，不是「內容」。空模板不會自己長出記憶。

| 檔案 | 用途 | 誰寫 |
|---|---|---|
| [`場景私有記憶.md`](場景私有記憶.md) | 場景記憶真源（§〇 交接 + 職責 + 決策） | 人 |
| [`定位卡.md`](定位卡.md) | 場景身分說明書（校驗的錨點） | 人 |
| [`身份卡.md`](身份卡.md) | 身分／權限／指紋 | **工具生成** |
| [`場景畫像.md`](場景畫像.md) | 布局／面板／依賴 | **工具生成** |
| [`交接規則.json`](交接規則.json) | **規則單一來源**（紅線等） | 人（少改） |
| [`派單模板.md`](派單模板.md) | 派單與回執格式（**回執三件套**） | 人 |
| [`工作流模板.md`](工作流模板.md) | 工作流定義格式（步驤／判據／門檻／分岔） | 人 |
| [`示範工作台/`](示範工作台/) | 一個**跑得起來**的最小範例 | —— |

---

## 怎麼用

```bash
# 1) 拷一份場景骨架
cp -r 04-模板/示範工作台/場景/示範場景 場景/我的場景/
cd 場景/我的場景 && git init      # ★ 場景邊界

# 2) 改定位卡（場景 id、名稱、面板路徑、專屬技能）

# 3) 改場景私有記憶的 §〇 與核心職責（把「待補」換掉）

# 4) 加到身份索引
#    場景/_場景身份索引.md 的表裡加一行（7 欄）

# 5) 讓工具蓋章
node 03-可執行工具/場景記憶.mjs stamp --場景 我的場景 --root .

# 6) 檢查（必須全綠）
node 03-可執行工具/場景記憶.mjs check --場景 我的場景 --root .
```

---

## ⚠️ 拷之前先知道這三件事

| # | 事情 | 為什麼 |
|---|---|---|
| 1 | **場景目錄一定要 `git init`** | 沒有 `.git` ⇒ 專屬技能不會被載入，場景邊界失效，而且**症狀不明顯** |
| 2 | **§〇 裡的「待補」要換掉** | 「核心職責」只有 3 條但都是「待補」⇒ 等於沒有職責，新會話不知道自己是誰 |
| 3 | **身份索引欄位要 7 欄對齊** | 少一欄 ⇒ 工具讀不到這張卡 ⇒ 校驗對這個場景完全失效 |

---

## 模板不包含什麼（要自己寫）

| 東西 | 為什麼不給 |
|---|---|
| 你的場景清單與劃分 | 這是**你的**職責結構，沒有通用答案 |
| 你的專案記憶 | 專案是你的，不是模板的 |
| 引擎相關設定 | 依引擎版本與環境而異，寫死反而害你 |
