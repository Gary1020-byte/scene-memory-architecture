# 場景憲法 · <場景名>（`<場景id>`）

> 本文件是本場景的「憲法層」，由引擎的 `agent-instructions` 注入到本場景會話的上下文里。
> 作用域：本目錄是獨立 git 倉庫 ⇒ 只有 cwd 落在本目錄樹內的會話才吃得到這份憲法。

## 我是誰

- 場景 id：`<場景id>` ｜ 場景名：<場景名>
- 定位卡：`./定位卡.md`（先讀它）
- 專屬技能：`<場景id>`（只在本場景倉庫內的會話可見）
- 記憶真源：`./場景私有記憶.md`（**唯一真源**，不是聊天記錄）

## 職責邊界（劃死，別越界）

- **負責**：見定位卡與 `./場景私有記憶.md` 的「核心職責」。
- **不碰**：別的場景的記憶目錄。發現別人寫錯 ⇒ **只能發請求，不許代改**。
- 只寫自己的 `./場景私有記憶.md`、`./專案記憶/`、`./歸檔/`。

## 記憶規則（最重要的四條）

1. **開場第一件事**：讀 `./場景私有記憶.md` 的 `## §〇 當前交接` —— 那裡寫著上次幹到哪兒、當前專案、下一步與卡點。
2. **§〇 ≤ 4 KB**，覆蓋寫；主文件 ≤ 25 KB；細節沉到 `## §五 決策與坑`（只追加）。
3. **寫回判據**：只記結論，不記過程；一次寫回 ≤ 10 行 / ≤ 2 KB。
4. **換會話前**：先寫交接 → 跑 `場景記憶.mjs check --場景 <場景名>`，**不過不許換**。

## 換會話協議（四步，第 ③ 步不能省）

1. 覆蓋寫 `§〇 當前交接`
2. 新建會話，舊會話歸檔
3. **同步三處**：場景 json 的 `sessionId` / 身份索引表的會話 id 欄 / `§〇` 交接署名
4. 自檢：`node <工作台根>/工具/場景記憶.mjs check --場景 <場景名>`

## 跨場景

- 只能發**通知 / 派單 / 回執**；⛔ 不許改對方的記憶。
- 留言：`node <工作台根>/工具/發消息.mjs --to <場景名> "內容"`（純檔案，不發網路請求）
- 派單四件套：**做什麼 · 判據 · 落盤位置 · 回執方式**；**一次派單 = 一條回執**。
- 對方不回 ⇒ 算「未回執」，別當已經幹完。

## 工具

```bash
node <工作台根>/工具/場景記憶.mjs list                    # 一覽所有場景缺什麼
node <工作台根>/工具/場景記憶.mjs check --場景 <場景名>    # 自檢
node <工作台根>/工具/場景記憶.mjs 交接 --場景 <場景名>    # 歸檔舊版 + 補 §〇
node <工作台根>/工具/發消息.mjs --list                    # 看跨場景留言
```
