# 派單模板

> 派單四件套：**做什麼 · 判據 · 落盤位置 · 回執方式**。
> 缺一件就會變成「做完了但沒人知道」。
>
> 回執三件套：**差異集合 · 可累積物 · 下一棒**。
> 缺可累積物 ⇒ **這次活白做**。

---

## 一、派單模板

```markdown
【<場景名> · 派單 · 請回執】

做什麼：
  <一句話的動作。要具體到不需要再問「所以要做什麼」。>

判據：
  ① <什麼算完成，可驗證>
  ② <量化門檻：數字、範圍、數量>
  ⛔ <本次不要碰什麼>

落盤位置：
  <完整檔案路徑；多個檔案就分行列>

回執方式：
  <回什麼、回在哪裡>
  ① 結論 + 證據 + 路徑
  ② 必須帶「差異集合」
  ③ 必須帶「可累積物」★ 少了這條＝這次活白做
  ④ 必須寫明「下一棒」
  ⑤ 寫回 ≤ 10 行 / ≤ 2 KB（可累積物不受此限）
```

---

## 二、回執模板

```markdown
【<場景名> · 回執】

結論：<一句話>
證據：<可點開的路徑 / commit / 數字>
路徑：<寫到哪了>

與上輪的差異：
  <項目A>：<舊值> → <新值>
  <項目B>：<舊值> → <新值>
  <刪了什麼 / 加了什麼>

可累積物：★ 少了這段＝這次活白做
  · <做法 / 判準：下次該怎麼做>
  · <坑：下次會踩什麼>
  · <更好的那次做法：這次改進了什麼>
  （落點：§五 決策與坑；會反覆用的請升級成場景專屬技能）

下一棒：<哪個場景接手 / 沒有了>

卡點：<無 / 等誰、等什麼>
```

> **回執不記「一切正常」。**
> 「一切正常」無法驗證——它可能是編的。
> 差異集合可對照：拿上輪的數字比對，就知道有沒有動。
>
> **可累積物是回執的主詞。** 差異集合回答「狀態變了什麼」，
> 可累積物回答「**認識變了什麼**」——後者才是讓下次不用從零開始的東西。

## 三、三個例子

### ✅ 好的派單（磁碟體檢）

```markdown
【場景丙 · 派單 · 請回執】

做什麼：
  找出 /mnt 下可清理的項目清單（舊備份、快取、日誌）。

判據：
  ① 列出每項的路徑、大小、预估可釋放量
  ② 總可釋放量 ≥ 1 GB 才算有結論；不足就明說「不足」
  ③ 每個項目標明「刪了會不會壞掉」
  ⛔ 本輪只清點，不刪任何東西

落盤位置：
  場景/場景丙/專案記憶/磁碟體檢-2026-10-31.md

回執方式：
  ① 結論 + 證據 + 路徑
  ② 帶「與上輪的差異」（上輪的數字要寫在派單裡，沒有就說「首輪，無上輪」）
  ③ 寫回 ≤ 10 行 / ≤ 2 KB
```

### ✅ 好的回執

```markdown
【場景丙 · 回執】

結論：/mnt 可釋放 3.2 GB，主要來自舊地圖備份與 Docker 映像。
證據：場景/場景丙/專案記憶/磁碟體檢-2026-10-31.md
路徑：同上

與上輪的差異（首輪，無上輪）：
  /mnt/minecraft  56% → （未動）
  可釋放總量     —  → 3.2 GB
  其中舊地圖備份  —  → 1.4 GB（3 個，2024-03 之前）
  Docker 映像     —  → 1.8 GB（2 個 dangling）

卡點：無。下一步等你確認要不要刪。
```

### ❌ 壞的派單

```markdown
幫我看看磁碟有點滿。
```

**為什麼不行**：
- 做什麼 → 模糊
- 判據 → 沒有（「有點滿」多滿算滿？）
- 落盤位置 → 沒有
- 回執方式 → 沒有

**後果**：回來一份「已清理，一切正常」——
無法驗證，而且很可能連要清什麼都沒清。

## 四、跨場景留言（不叫醒對方的那條通道）

```markdown
- [2026-10-31 09:12] → <場景名>：【派單·請回執】<一行摘要，細節看共享看板>
```

| 特性 | 說明 |
|---|---|
| 零網路請求 | 純檔案寫入，對方不醒著也能收 |
| 只能等回執 | 沒辦法主動確認對方看過了 |
| 必須雙寫 | 共享看板 + 收件方的 `## 〇-通知` |

> ⚠️ **雙寫是「看板分裂」的來源。**
> 兩個腳本寫到不同路徑時，收件方根本收不到，而表面完全看不出來。
> 修法是**統一路徑解析**，不是「記得寫兩邊」——
> 見[已知裂縫 #3](../02-落地實作/四-已知裂縫與待修.md)。

## 五、派單的四件套為什麼不能省

| 件 | 省的後果 |
|---|---|
| **做什麼** | 對方猜錯範圍，做了另一件事 |
| **判據** | 回執無法判定真假（「好了」算不算好？） |
| **落盤位置** | 成果散在對方那裡，你找不到；或寫到兩份 |
| **回執方式** | 活幹完了，但你不知道 |

> **一次派單 = 一條回執。**
> 「活幹完了但對方還不知道」＝**沒幹完**。
