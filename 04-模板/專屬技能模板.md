# <場景名> · 場景專屬技能

1. **接手**：讀 `./場景私有記憶.md` 的 `## §〇 當前交接`（≤4 KB，五小節：上次交接 / 當前專案 / 私有記憶變更 / 下一步·卡點 / 全貌）。
2. **幹活**：只碰本場景的目錄與本場景的記憶；別人的地盤只發請求。
3. **寫回**：把結論寫回 `§〇`（≤10 行/≤2 KB，只記結論不記過程）；細節追加進 `## §五 決策與坑`。
4. **交接**：收工或換會話前跑 `node <工作台根>/工具/場景記憶.mjs 交接 --場景 <場景名>`，然後 `check` 通過才換。
5. **跨場景**：`node <工作台根>/工具/發消息.mjs --to <場景名> "內容"`；派單要寫清 做什麼·判據·落盤位置·回執方式。

> ⚠️ **description 裡的路徑要填場景目錄的絕對路徑** —— 那是引擎判斷
> 「這個技能在不在本場景可見」的依據。填錯 ⇒ 技能會在別的場景也露出來。
