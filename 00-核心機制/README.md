## 四篇怎麼串起來

```
二-場景體系  ──劃出邊界──▶  一-場景記憶  ──讓狀態不丟──▶  三-派單與回執
    (誰管什麼)              (怎麼記)                    (怎麼派、怎麼收回)
        │                                                      │
        └──────────────── 四-兩套記憶的分工 ◀──────────────────┘
              (檔案派 vs 語意派：這一切是「哪一層」的問題)
```

**一句話概括整個板塊：**

> **路由靠目錄，送達靠 RPC，留痕靠檔案，驗證靠 fail-closed。**
