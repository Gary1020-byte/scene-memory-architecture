## 這四篇的用處

方法論文件容易讓人「照著做」，但很少回答兩個問題：
**「我這情況該用哪一套？」** 和 **「這件事該派給場景還是派給 sub-agent？」**

這四篇就是來回答它們的。每一篇都給出**判據**（看什麼來決定），
而不是只有**結論**（該用哪個）。

第一篇是新的主線：**sub-agent 不是壞的，是不能承載累積。**
先把這件事講清楚，後面三篇的選型才有地基。
