## 這三篇的用處

方法論文件容易讓人「照著做」，但很少回答一個問題：
**「我這情況該用哪一套？」**

這三篇就是來回答它的。每一篇都給出**判據**（看什麼來決定），
而不是只有**結論**（該用哪個）。
