## 這張圖要看什麼

**節點 = 東西放在哪一層；連線 = 誰讀誰、誰寫誰。**

圖上有兩種連線，別搞混：

| 連線 | 意思 |
|---|---|
| **實心帶箭頭** | 資料流（注入、派單、回執、寫入） |
| **虛線** | 稽核（git log、審計日誌）——不傳資料，只留痕 |

---

## 層號怎麼讀

> ⚠️ **層號是「歸屬層級」，不是「由上到下的順序」。**
> 圖上由上到下是**主資料流**：L0 → L2 → L1 → L3 → L4/L5
> （C6 回執是例外，往上走）。

層號的完整定義在 [`總綱.md`](../總綱.md) 的「七層」表。
